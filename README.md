### Ce que je construis

- **Des assistants qui agissent** : voix, outils système, plusieurs modèles routés
  selon la tâche, rien qui parte chez un tiers sans le dire.
- **De l'automatisation vérifiable** : un résultat n'est livré que s'il a été
  contrôlé, et une règle métier inconnue est posée en question, pas inventée.
- **Du bas niveau quand il le faut** : C, processus, signaux, embarqué.
